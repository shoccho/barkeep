How to hide the battery percentage on Samsung One UI 9 & 8.5

Updated November 2026 · 4-minute read

Short answer: One UI 9 has no setting that shows the battery icon without the number. You get the battery with the percentage inside it, or the percentage on its own. To keep the icon and hide the percentage, install the free app Barkeep. It hides Samsung's battery and draws a number-free battery icon in exactly the same place.

It works on Galaxy phones with One UI 8.5 or 9 (Android 16 or later), takes about five minutes to set up, and turns off in one tap.

Why One UI can't do it on its own

Samsung redesigned the status bar battery so the percentage lives inside the battery icon. One UI 9's battery options give you the battery with the percentage inside it, or the percentage on its own — there's no option for the icon alone. Every choice either keeps the number or drops the icon.

Step by step: hide the battery percentage with Barkeep

  1. Install Barkeep

    Download Barkeep.apk and open it. Allow installs from your browser when asked. If One UI blocks it, turn off Auto Blocker (Settings › Security and privacy › Auto Blocker) for the install.

  2. Allow “Appear on top”

    Open Barkeep and flip the main switch. It takes you to the setting; allow it. A battery icon without a number appears right away, beside the camera.

  3. Run the one-time adb command

    This lets Barkeep hide Samsung's own battery. Turn on USB debugging (Settings › About phone › Software information › tap Build number 7 times, then Developer options › USB debugging). Connect your phone to any computer, open app.tangoapp.dev in Chrome or Edge, connect, open Shell and run:

    pm grant com.github.shoccho.barkeep android.permission.WRITE_SECURE_SETTINGS

    Nothing to install. If you already have adb, run it with adb shell in front. More on this step.

  4. Turn on the accessibility service

    In Barkeep, open Permissions and tap Turn on. Barkeep uses it only to find Samsung's battery on screen and read the status bar icon colour.

  5. Put it where Samsung's battery was

    Under Position, pick Own icons: Samsung's battery and right-side icons are hidden and Barkeep redraws them, with a number-free battery at the far right. Or pick Samsung's spot, which paints a solid battery icon exactly over Samsung's numbered one. Then choose a style: Capsule, Classic, Dot, Camera ring or Edge line.

Getting the percentage back

Turn the pill off in Barkeep or from its Quick Settings tile. Samsung's battery, with its percentage, and your status icons come back exactly as they were. Barkeep keeps track of which changes are its own, so your other settings are never touched.

Questions

Is there a setting in One UI 9 to show the battery icon without the percentage?

No. One UI 9 shows the battery with the percentage inside it, or the percentage alone. To keep the icon and drop the number you need an app such as Barkeep.

Can Good Lock's QuickStar hide the battery percentage?

QuickStar can hide the battery icon completely, but it can't keep the icon without the number. Barkeep hides Samsung's battery the same way and draws a number-free battery icon in its place.

Does it work on One UI 8.5 and other Galaxy phones?

Barkeep needs Android 16 or later, so it installs on One UI 8.5 and One UI 9. It's tuned on a Galaxy A56; other Galaxy phones should work but haven't been tested.

How do I get the battery percentage back?

Turn Barkeep's pill off, from the app or its Quick Settings tile. Samsung's battery and status icons come back exactly as they were.

Do I need a computer?

Only for the one-time adb step, and only for a minute: a browser-based adb at app.tangoapp.dev runs it from Chrome or Edge with nothing to install. Without it, Barkeep can still cover Samsung's number using Samsung's spot.
