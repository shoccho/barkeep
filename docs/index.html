The idea

See how full it is at a glance. Skip the number.

A shape tells you everything you need — mostly full, half, nearly empty — without a percentage pulling your eye every time you look at the screen. Barkeep puts that shape exactly where Samsung's battery lives, so nothing else on your status bar has to move.

Privacy

It can't phone home. It has no way to.

No internet permission.

Android never gives Barkeep network access, so nothing about you or your phone can leave it. No ads, no analytics, no account.

Accessibility, used narrowly.

The optional accessibility service reads only where Samsung's battery icon is and what colour the status bar icons are. It doesn't read, store or send anything you type or see.

Everything is reversible.

Turn the pill off and Samsung's battery and status icons come back exactly as you had them. Barkeep keeps track of which changes are its own.

Download APK

  1. Download and open the APK

    Your browser asks to allow installs from this source the first time — allow it, then tap Install. If One UI says the install was blocked, turn off Auto Blocker (Settings › Security and privacy › Auto Blocker) just for the install, then turn it back on.

  2. Allow "Appear on top"

    The only required permission. Flip the main switch in Barkeep and it takes you straight there.

  3. Allow unrestricted battery use Recommended

    Stops One UI from putting the pill to sleep in the background. Barkeep has an Allow button for it under Permissions.

  4. Do the one-time adb step Recommended

    One command, run once, from a computer — in your browser, no install needed. It lets Barkeep hide Samsung's battery and icons (needed for Own icons) and turn its accessibility service on with one tap.

  5. Turn on the accessibility service For Samsung's spot, Own icons, Match icons

    After the adb step, just tap Turn on under Permissions in Barkeep. Without it: Settings › Accessibility › Installed apps › Barkeep. If that switch is greyed out as a restricted setting, open Barkeep's App info, tap ⋮ in the top corner, choose Allow restricted settings, and try again.

  6. Allow Phone & Nearby devices Optional, for Own icons

    Phone shows both SIMs and the 5G / 4G label; Nearby devices shows when Bluetooth is connected. Both are under Permissions in Barkeep.

The one-time adb step

Give Barkeep its extra permission

Android only lets a computer grant this permission, over USB. You do it once; it stays after you unplug, restart or update Barkeep.

First, on your phone: turn on USB debugging. Settings › About phone › Software information › tap Build number 7 times. Then Settings › Developer options › turn on USB debugging.
  1. Plug your phone into a computer with a USB cable.
  2. On the computer, open app.tangoapp.dev in Chrome or Edge. Choose to add a USB device, pick your phone and connect.
  3. On the phone, tap Allow when it asks “Allow USB debugging?”.
  4. In Tango, open Shell, paste this and press Enter:
    pm grant com.github.shoccho.barkeep android.permission.WRITE_SECURE_SETTINGS
  5. Back in Barkeep, Permissions now shows the adb grant as done. You can turn USB debugging off again.

Tango is a free, open-source ADB that runs inside the browser using WebUSB. It isn't part of Barkeep. It works in Chrome, Edge and other Chromium browsers, not Safari or Firefox. If adb is already running on that computer, quit it first (adb kill-server) — only one program can talk to the phone at a time. Tango can also install the APK for you, and runs any command from the other tab — leave out the adb shell part.

With Android platform-tools installed and your phone plugged in:

adb shell pm grant com.github.shoccho.barkeep android.permission.WRITE_SECURE_SETTINGS

Optional — set up everything else from the computer too. Each of these can also be done in the app.

FAQ

Questions

Will it work on my phone?

Barkeep needs Android 16 or later — One UI 8.5 or One UI 9. It's built and tuned on a Galaxy A56 running One UI 9, and the default sizes match that phone's stock battery. Other Galaxy phones on One UI 8.5 or 9 should work, and Free placement works on any Android 16+ phone, but they haven't been tested.

Why does it need "Appear on top"?

That's how an app draws over the status bar. Without it, there's nowhere to put the pill.

Why the accessibility service?

It's optional. It lets Barkeep draw above the status bar in Samsung's exact battery spot and read the colour of the status icons for Match icons. It reads nothing else.

Why an adb command?

Hiding Samsung's own icons uses a system setting only adb can unlock — the same switch Good Lock's QuickStar flips. You run it once, and you don't need to install anything: a browser-based adb does it from Chrome or Edge. Without it, everything except hiding Samsung's icons still works.

Can I do the adb step without a computer?

Not from Barkeep itself — Android only lets this permission be granted over adb. The browser route needs any computer with Chrome or Edge for a minute; nothing gets installed on it.

How do I get Samsung's battery back?

Turn the pill off — from the app or the Quick Settings tile. Barkeep restores Samsung's battery and status icons exactly as they were.

Does it drain the battery?

The charging shimmer pauses when the screen is off, and Match icons samples colour only in short bursts while the screen is changing, backing off in busy apps.

Does it ship Samsung's icons?

No. In Own icons, Barkeep borrows the icon art already installed on your phone with One UI, and falls back to its own drawn icons if any are missing.
